# ParadaYa Android

Отдельный Android-проект с логикой из текущего веб-приложения:
- загрузка остановок EMT Valencia
- поиск и сортировка по расстоянию
- избранные остановки (DataStore)
- ETA для избранных
- Home Screen Widget с избранными остановками
- автообновление виджета раз в минуту через `AlarmManager` + `BroadcastReceiver`

## Где лежит

`/Users/cash/Documents/workspace/bus-stop-finder/android-paradaya`

## Как запустить

1. Открой папку `android-paradaya` в Android Studio.
2. Дай IDE синхронизировать Gradle-проект.
3. Запусти `app` на эмуляторе или устройстве.

## Что нужно проверить после запуска

1. Разрешить геолокацию в приложении.
2. Добавить несколько остановок в избранное.
3. Добавить виджет `ParadaYa` на домашний экран.
4. Проверить, что ETA и расстояния в виджете обновляются (каждую минуту, best effort по ограничениям Android).

## Важная заметка про обновления каждую минуту

Android может ограничивать фоновые обновления (Doze, battery optimization, exact alarm policy). В проекте сделано максимально близко к минутному обновлению через `setExactAndAllowWhileIdle` (когда разрешено), иначе используется ближайший доступный режим.
